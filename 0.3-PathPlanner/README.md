# 0.3 Path Planner
In this lesson, students explore programming in FRC by making and testing autonomous paths. This lesson does not require any prior programming knowledge, so it is a useful tool to get students interested in the subteam. Students will make and debug a pathplanner path that can navigate around three cones.
## Setup
* This lesson is designed for use with an existing robot already using PathPlanner. 
* In pathplanner, make sure the robot being used is selected.
* In pathplanner, select [background.png](background.png) as the custom field image. 
* Create a play area with 3 cones that match this background image. 
* It is recommended to use `AutoBuilder.buildAutoChooser()` so students do not need to precisely name their autos. 
* It is recommend to make a new branch in the existing robot code with all existing paths removed to keep the PathPlanner UI clean.

This folder contains [slides](slides.pdf) that could be helpful to explain the process to make the pathplanner path and auto.
